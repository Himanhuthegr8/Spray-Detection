==============================================================
  SPRAY DETECTION PROJECT — NEW PC SETUP GUIDE
  Hardware: HP + NVIDIA Titan RTX 24GB
  OS: Windows 11
==============================================================

STEP 1 — NVIDIA DRIVER
==============================================================
Download and install the latest NVIDIA driver for Titan RTX:
  https://www.nvidia.com/en-us/drivers/

  → Product Type: Desktop (or Workstation if applicable)
  → Product Series: Titan RTX
  → Download and run the installer (choose "Express Install")

After install, verify in PowerShell:
  nvidia-smi

You should see "NVIDIA Titan RTX" and "24564MiB" total memory.

--------------------------------------------------------------

STEP 2 — PYTHON 3.12
==============================================================
Download Python 3.12 (same version as the laptop):
  https://www.python.org/downloads/release/python-3128/

  → Download "Windows installer (64-bit)"
  → During install: CHECK "Add Python to PATH" ← CRITICAL
  → Click "Install Now"

Verify in PowerShell:
  python --version
  # Should print: Python 3.12.x

--------------------------------------------------------------

STEP 3 — CUDA TOOLKIT 12.1
==============================================================
PyTorch 2.5.1 (which we use) requires CUDA 12.1:
  https://developer.nvidia.com/cuda-12-1-0-download-archive

  → Operating System: Windows
  → Architecture: x86_64
  → Version: 11 or 10
  → Installer Type: exe (local)
  → Download and run

Verify after install (open a NEW PowerShell window):
  nvcc --version
  # Should print: Cuda compilation tools, release 12.1

--------------------------------------------------------------

STEP 4 — INSTALL ALL PYTHON PACKAGES
==============================================================
Open PowerShell and run these commands ONE BY ONE:

  # 1. Upgrade pip first
  python -m pip install --upgrade pip

  # 2. Install PyTorch with CUDA 12.1 support (MOST IMPORTANT)
  #    This is a big download (~2.5GB) — be patient
  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

  # 3. Verify GPU is detected by PyTorch
  python -c "import torch; print('CUDA available:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0)); print('VRAM:', round(torch.cuda.get_device_properties(0).total_memory/1e9, 1), 'GB')"
  # Should print: CUDA available: True | GPU: NVIDIA Titan RTX | VRAM: 24.0 GB

  # 4. Install Ultralytics (YOLO)
  pip install ultralytics

  # 5. Install OpenCV
  pip install opencv-python

  # 6. Install scikit-image (for skeleton detection in spray_physics.py)
  pip install scikit-image

  # 7. Install numpy (usually installed as dependency, but just in case)
  pip install numpy

  # 8. Everything else needed
  pip install scipy matplotlib pandas tqdm

STEP 7 — RETRAIN WITH FULL 24GB VRAM POWER (OPTIONAL)
==============================================================
With 24GB VRAM (vs 6GB on laptop), you can use:
  - Batch size: 16 (was 2 on laptop → 8× faster training!)
  - Image size: 640 (was 480 → better accuracy!)

Generate fresh dataset (if not copied):
  python prepare_yolo_dataset.py --output yolo_dataset_v3

Train at full power — estimated time: ~2 hours (vs 10 hours on laptop):
  python train_yolo.py --data yolo_dataset_v3/data.yaml --model yolov8n-seg.pt --batch 16 --imgsz 640 --epochs 60 --patience 15 --name spray_seg_titan

Run inference on Drop.avi:
  python infer_video.py --model runs/segment/spray_seg_titan/weights/best.pt --conf 0.15

QUICK TROUBLESHOOTING
==============================================================

Problem: "CUDA not available" after installing PyTorch
Fix: Make sure you installed the cu121 version of PyTorch (Step 4)
     Reinstall: pip uninstall torch torchvision torchaudio -y
     Then: pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

Problem: "'python' is not recognized"
Fix: Re-run Python installer, make sure "Add to PATH" was checked

Problem: "nvidia-smi not found"
Fix: NVIDIA driver not installed or PATH not set. Reinstall driver.

Problem: CUDA version mismatch
Fix: Check your CUDA version with: nvidia-smi (top right corner shows "CUDA Version: X.X")
     If it shows 12.4 or higher, the cu121 PyTorch still works fine.
     If it shows 11.x, use: --index-url https://download.pytorch.org/whl/cu118
